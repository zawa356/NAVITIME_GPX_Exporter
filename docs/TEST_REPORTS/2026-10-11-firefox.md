## Source-to-export fidelity (private offline comparison)
- Original source: pre-existing JSON exported from the user's own NAVITIME account, held only in the private test environment.
- Output: locally downloaded GPX provided directly by the same user.
- GPX syntax: successfully parsed by XML parser; root namespace matches GPX 1.1 and version is 1.1.
- Track segments: **1 actual vs. 1 expected**.
- Track points: **2,779 actual vs. 2,779 expected**.
- Coordinates: **0 mismatches** across all points, preserving point order; numeric decimal comparison.
- Altitude: **0 mismatches** across all points, including presence of `ele`.
- Timestamps: **0 mismatches** across all points, comparing offset-aware instants; UTC normalization did not change point times.
- GPX metadata: name and ride start time included; filename format and its local-time start prefix conform to requirements.
- Measured filename length and title not recorded here to avoid inadvertent personally identifying ride information.

## Limits of this PASS
- Well-formed XML and namespace checks are **not a full GPX 1.1 XSD validation**. XSD acceptance remains open.
- Comparison proves preservation relative to the source JSON, **not the GPS/altitude's physical accuracy**.
- No Chrome or Edge live test has been performed, nor a Firefox signed install or store review.
- Original service metadata's end timestamp differed from the last recorded point by 2 seconds; last point was identical between JSON and GPX, so **this is not an export loss**.
